Система для личного кабинета инвестиционного страхования жизни (ИСЖ): главная кабинета, витрина программ, пошаговое оформление программы и инвест-опросник. Интерфейс тёплый и спокойный: почти белый фон, чёрные пилюли-кнопки, один розовый акцент на экран.

## Тон и тексты

- Пишите на «вы», коротко и по делу: «Выберите стратегию», «Далее», «Назад».
- Кнопки — глагол или короткое действие с заглавной буквы: «Оформить», «Подробнее». Без восклицательных знаков и эмодзи.
- Цифры доходности и сроков — главное содержание карточек: «Доходность за 3 года», «Шаг 2 из 4».
- Надписи ПРОПИСНЫМИ — только стилем `kaps` (разрядка +5%), например «НА ПРОСМОТР».

## Цвет

- Фон страницы — `bg`; вторичные поверхности, светлые кнопки и активный пункт навигации — `bg-2`; белые карточки — `white`.
- Основной текст — `text`; вторичный — `grey` (на `white` 4,5:1, на `bg-2` 4,0:1 — для мелкого текста держите `grey` на белом).
- Главные кнопки — `black` с белым текстом.
- `pink` — единственный акцент: кнопка Accent, «Далее», выбранный ответ. Один розовый элемент на экран. Белый текст на `pink` — 3,1:1, ниже нормы для 14–16 px (так в макете).
- `blue` — второй, декоративный цвет для графики и заливок; текстом не используйте.
- Подложки чипов статуса — `green-chip`, `blue-chip`, `peach-chip` (15% непрозрачности) под текстом `text`. Мягкая розовая подложка — `pink-bg`.
- Рамки и разделители — `stroke`; `grey-2` — для неактивных элементов, не для текста.

## Типографика

Один шрифт — Onest (`--font-sans`), файл `fonts/Onest-var.woff` (переменный, 100–900, лицензия OFL в `licenses/OFL-Onest.txt`).

- Десктоп: `bolshoy-zagolovok` 84 — hero; `zagolovok` 54 — заголовок страницы; `zagolovok-1` 48 и `zagolovok-2` 38 — секции и блоки; `podzagolovok` 24 — подзаголовки и цифры; `osnovnoy-tekst` 16 Light — абзацы, навигация, шаги; `tekst` 14 — подписи кнопок; `kaps` 16 — капс.
- Мобильный: `mob-zagolovok-ekrana-L` 32 и `-S` 28 SemiBold — заголовок экрана; `mob-zagolovok-bloka` 20 — заголовок блока; `mob-osnovnoy-tekst` 16/24; `mob-leybl` 14 Medium — подписи полей; `mob-podpis` 12 — сноски.
- Заголовки и текст идут с трекингом −2% (`-0.02em`), большой заголовок — −3%; мобильные заголовки экрана — без трекинга.

## Отступы, радиусы, формы

- Отступы только из шкалы `space-*` (0–160). Кнопки: `space-16` по вертикали, `space-28` по горизонтали; секции страницы — `space-64`…`space-160`. `space-negative-28` — для наезда блоков друг на друга.
- Формы мягкие: кнопки-пилюли `radius-36` / `radius-40`, пилюли навигации `radius-100`, варианты ответа `radius-16`, карточки — `radius-20`…`radius-68`.
- Теней в файле нет: блоки отделяются цветом поверхности (`bg` → `bg-2` → `white`), а не тенью.

## Иконки

Иконки в макете — линейные, 20×20: шеврон вниз (Sort, WithIcon), стрелки вправо и влево (ActionButton), галочка 10×8 в кружке (AnswerOption). Компоненты принимают иконку через проп (`icon`, `checkIcon`) и сами её не рисуют. Эмодзи вместо иконок не используйте.

## Компоненты

React-компоненты лежат в `window.KabinetDS` (`components/bundle.js` + `components/bundle.css`, нужен React 18). Названия и варианты повторяют Figma.

- Атомы: `Button` (`type`), `ActionButton` (`direction`), `NavigationItem` (`active`), `AnswerOption` (`selected`).
- Молекулы: `ProductCard`, `SectionHeader` (`size`), `FinancialGoalCard`, `PromoCard`, `DocumentConsentCard` (`checked`), `AccrualCard` (`type`), `MiniProductCard` (`color`), `ConditionCard` (`state`), `NavigationControls`, `BondCard`, `FeeRow`, `MetricCard`, `ProfileCard`, `HistoricalReturnCard`, `ConditionsList`.

Иллюстрации и иконки компоненты получают через пропсы (`image`, `icon`, `checkIcon`). Без `image` карточки показывают градиентную заглушку из `answer-selected-from` → `answer-selected-to` — в продукте всегда передавайте картинку. Описания компонентов и пометки у токенов пересказывают описания из Figma-файла.

## Изображения

Иллюстрации — мягкие пастельные 3D-формы (сферы, листья, монеты, столбики) в розово-голубой гамме с белым светом; в карточках они уходят за правый нижний край с прозрачностью 60–80%. Промо-картинки — размытые цветочные и абстрактные фото в той же гамме.
