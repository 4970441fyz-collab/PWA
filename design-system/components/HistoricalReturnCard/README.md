# HistoricalReturnCard

Карточка с описанием исторической доходности стратегии на градиентном фоне.

Ширина 100% (макс. 852 px), горизонтальный градиент `hist-from` → `hist-via` (59,6%) → `hist-to`, отступ `space-32`, `radius-32`, зазор `space-28`; внутри колонка (`space-12`): заголовок `t-caps` цветом `text` и описание `t-body c-grey`. Токены `--hist-from/via/to` нужно добавить в систему (#eaeff8, #f7e9ee, #eee7f8).

**Что передаёт потребитель:** `title`, `text`.

Не импортировано: декоративный SVG-блоб (180 px, поворот -41,86°, справа сверху, частично за краем) — опущен. Контраст: `grey` на светлом градиенте достаточный.
