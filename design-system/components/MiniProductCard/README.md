# MiniProductCard

Компактная карточка стратегии: название и состав.

Отступ `space-28`, зазор `space-16`, `radius-24`; название `podzagolovok`, состав — «Основной текст». Цвет фона (Color 1/2 в Figma): `bg` по умолчанию, `color: '2'` — `bg-2`. Выбирайте фон, контрастный к подложке: на `bg-2` ставьте Color 1, на `bg` — Color 2.

**Что передаёт потребитель:** `title`, `description`, `color`.
