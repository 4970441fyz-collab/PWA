# AccrualCard

Карточка ближайшего начисления купона или платежа по договору: иконка, сумма и дата.

Фон `bg`, 320 px, `radius-16`, отступ `space-20`. Слева иконка 20 px в круге `pink-bg`; в центре подпись («Купон» / «Платеж», `grey`), сумма стилем `podzagolovok` и пояснение `grey-2`; справа дата `grey-2`.

`grey-2` на `bg` — около 1,7:1, такой текст плохо читается; так в макете. Для важной даты лучше `grey`.

**Что передаёт потребитель:** `type` ('Coupon' | 'Payment'), `amount`, `date`, при желании `note`, `icon` (процент для купона, карта для платежа — из Figma не импортированы).
