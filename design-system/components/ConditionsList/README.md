# ConditionsList

Сетка условий программы в две колонки: каждая ячейка — `ConditionCard` (метка и значение).

Колонки равной ширины, зазор `space-12`, ширина в макете 404 px (здесь — до 404 px, растягивается по контейнеру). Карточки на фоне `bg`, поэтому сетку ставьте на подложку `bg-2` или `white` — на `bg` карточки сольются с фоном.

По умолчанию — 6 условий из макета: «Комиссия за вход — 0%», «Состав стратегии — Облигации», «Выплаты — Ежемесячно», «Минимальная сумма — от 6 млн», «Срок — Бессрочный», «Налог — Только с прибыли».

**Что передаёт потребитель:** `items` — массив `{ label, value, state? }`.
