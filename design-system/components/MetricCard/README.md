# MetricCard

Карточка с одним показателем: подпись сверху и крупное значение снизу.

Фон `bg-2`, 370×420 px, `radius-32`, отступ `space-28`, колонка с `justify-content: space-between`, цвет текста `text`. Сверху подпись стилем `t-caps` (по умолчанию «Активных договоров»), снизу значение стилем `t-z2` 38 px (по умолчанию «Пока нет»).

**Что передаёт потребитель:** `label`, `value`. Иконки и изображения не используются.
