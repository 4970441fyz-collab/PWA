# ConditionCard

Плашка одного условия программы: метка и значение.

Фон `bg`, ширина 196 px, отступ `space-16`, зазор `space-4`, `radius-16`. Метка — `tekst`: `grey` (State=Default) или `grey-2` (State=Alternative); значение — «Основной текст».

**Что передаёт потребитель:** `label`, `value`, `state`.
