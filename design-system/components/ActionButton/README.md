# ActionButton

Кнопка перехода между шагами: «Далее» со стрелкой вправо и «Назад» со стрелкой влево.

- `Next` — `pink`, белый текст, стрелка справа. Переход к следующему шагу оформления или опроса.
- `BlackArrow` — то же на `black`, когда розовый акцент на экране уже занят.
- `Back` — `bg-2`, текст `grey`, стрелка слева.

Радиус `radius-40`, отступы `space-16` / `space-28`, подпись — «Основной текст» (16, Light, межстрочный `500` = 20 px).

**Что передаёт потребитель:** `onClick`, при необходимости свою подпись, стрелку 20×20 в `icon`. Стрелки из файла не импортированы.

Ставьте пару «Назад / Далее» в один ряд: «Назад» слева, «Далее» справа.
