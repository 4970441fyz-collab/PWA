# AnswerOption

Вариант ответа в опроснике (инвест-квиз): светлая плашка, а выбранная — с розовой рамкой, градиентом и галочкой.

- невыбранный — `bg-2`, высота 56 px, радиус `radius-16`, отступ `space-28`.
- выбранный — рамка 1,5 px `answer-selected-border`, градиент слева направо `answer-selected-from` → `answer-selected-to`, справа кружок 24 px `pink` (`radius-12`) с галочкой; высота 59 px.

Текст `black`, «Основной текст». Ширина в макете 200 px — растягивайте по контейнеру через `className`.

**Что передаёт потребитель:** подпись, `selected`, `onClick`; галочку 10×8 — в `checkIcon` (из файла не импортирована). Группу вариантов оборачивайте в `role="radiogroup"` с `aria-label`.
