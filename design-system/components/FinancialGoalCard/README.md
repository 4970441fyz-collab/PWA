# FinancialGoalCard

Большая карточка финансовой цели с иллюстрацией на весь фон: капс-надпись сверху и глагол цели внизу.

Варианты Goal из Figma: Save («Фиксированная доходность» / «Сохранить»), Invest («Юниты» / «Инвестировать»), Accumulate («Накопительное страхование» / «Накопить»). Карточка 408×513, `radius-32`, отступ `space-32`; поверх иллюстрации — градиент `goal-fade-0` → `goal-fade` от 53% высоты вниз, чтобы читался заголовок `zagolovok-1`.

**Что передаёт потребитель:** `eyebrow`, `title`, `image` — URL иллюстрации. Иллюстрации из Figma не импортированы; без `image` — градиентная заглушка.
