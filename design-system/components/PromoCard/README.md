# PromoCard

Промо-карточка акции для блока «Актуально сейчас»: картинка, капс-заголовок и короткое условие.

Плашка `bg-2` 295×354, `radius-32`, отступ и зазор `space-20`; картинка высотой 189 px со скруглением `radius-16`; заголовок стилем `kaps`, описание — `tekst` цветом `grey`. Варианты Campaign из Figma (NoCommission, CreditInsurance, Mortgage, EndowmentInsurance) отличаются только картинкой и текстом.

**Что передаёт потребитель:** `title`, `description`, `image`. Картинки акций из Figma не импортированы. В тексте макета есть опечатки («комисии», «учувствуйте») — в продукте пишите «комиссии», «участвуйте».
