# ProductCard

Карточка продукта (стратегии) на витрине: название, состав, чип с периодичностью выплат и крупная цифра ожидаемой доходности.

Структура как в Figma: внешняя плашка `bg-2` (`radius-32`, отступ `space-16`), внутри белый блок `radius-24` с отступом `space-28`, иллюстрацией в правом нижнем углу, чипом и названием (`zagolovok-2`); под ним цифра доходности (`zagolovok-2`) и подпись `grey`. Размер в макете 396×448.

**Варианты Background 1–6** различаются только иллюстрацией и цветом чипа: синий `blue-chip` (по умолчанию), `chipColor: 'peach'` (`peach-chip`), `chipColor: 'green'` (`green-chip`).

**Что передаёт потребитель:** `title`, `description`, `subtitle` (текст чипа), `performanceValue`, `performanceLabel`, `image` — URL иллюстрации. Иллюстрации из Figma (6 штук) не импортированы; без `image` показывается градиентная заглушка.
