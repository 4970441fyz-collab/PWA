# NavigationItem

Пункт навигации в виде пилюли высотой 48 px; текущий раздел подсвечен фоном `bg-2`.

- `active` — фон `bg-2`, рендерится с `aria-current="page"`.
- неактивный — фон `white`.

Текст `text`, стиль «Основной текст», отступы по бокам `space-20`, радиус `radius-100`.

**Что передаёт потребитель:** подпись, `href`, флаг `active` для текущего раздела. Ряд пунктов собирайте в `<nav>` с зазором `space-8`.
