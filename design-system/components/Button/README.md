# Button

Кнопка-пилюля для действий на странице: чёрная по умолчанию, розовая для главного действия, светлая для второстепенного.

**Варианты (`type`, как в Figma):**
- `Primary` — `black`, белый текст, радиус `radius-36`. Обычное действие.
- `Accent` — `pink`, белый текст. Одно главное действие на экране («Оформить»).
- `Outline` — `bg-2`, текст `grey`, радиус `radius-40`. Второстепенное действие.
- `Sort` — как Primary, но с иконкой справа (шеврон вниз): открывает сортировку.
- `WithIcon` — как Outline, с иконкой справа: открывает список или фильтр.

Отступы `space-16` / `space-28`, зазор подпись–иконка `space-16`; подпись — стиль «Текст» (14/16).

**Что передаёт потребитель:** подпись (`children`), обработчик `onClick`, для Sort/WithIcon — иконку 20×20 в `icon`. Иконки из файла не импортированы; используйте шеврон из своего набора.

Белый текст на `pink` даёт 3,1:1 — меньше 4,5:1 для 14 px. Так в макете; для важных подписей держите Accent короткой и крупной или используйте Primary.
