# FeeRow

Строка таблицы комиссий: процент, описание и период.

Отступы `space-12` по вертикали и `space-4` по бокам, зазор `space-16`. Значение — `kaps` в колонке 48 px, описание — `tekst` `grey`, период — `tekst` `grey-2` (1,7:1 на светлом фоне — так в макете).

**Что передаёт потребитель:** `value`, `description`, `period`. Несколько строк подряд образуют таблицу комиссий (fee-table в Figma).
