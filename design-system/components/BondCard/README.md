# BondCard

Карточка облигации в составе стратегии: тикер, тип и доходность.

Фон `bg-2`, 279 px, `radius-24`, отступ `space-20`, зазор `space-16`. Сверху тикер стилем `kaps` и тип (`tekst`, `grey`), разделитель, снизу доходность `podzagolovok` и подпись «Доходность».

Разделитель в Figma — векторная линия; здесь он нарисован линией 1 px цвета `stroke`.

**Что передаёт потребитель:** `name`, `description`, `yieldValue`, `yieldLabel`.
