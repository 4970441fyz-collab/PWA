# ProfileCard

Карточка профиля клиента: имя, аватар и статус инвестора.

Фон `bg-2` (поверх него опциональная картинка с непрозрачностью 48%), 484×572 px, `radius-32`, отступ `space-32`, колонка `space-between`. Сверху: подпись `t-body` и имя `t-z1` (зазор `space-16`), ниже через `space-60` аватар 133 px с `radius-68`. Снизу плашка статуса: фон `blue`, текст `white` `t-text`, отступы `space-12`/`space-28`, `radius-36`.

**Что передаёт потребитель:** `name`, `status`, при желании `caption`, `avatar` и `backgroundImage` (URL; из Figma не импортированы, без них показывается градиентная заглушка).

Белый текст на `blue` — около 2,4:1, ниже нормы читаемости (так в макете): держите статус коротким.
