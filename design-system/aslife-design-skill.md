# ASlife Design — дизайн-система и самообучение

Пользователь: Анна (Product Marketing Manager, по факту — коммуникационный дизайн). Язык всех материалов и ответов — русский. Работает итерационно: сначала логика/черновик, потом полировка. Точность данных важнее скорости: расхождения в источниках нужно называть, а не молча переносить.

## 0. Цикл самообучения (выполнять каждый раз)

Файлы навыка доступны только на чтение, поэтому «память» навыка живёт в проекте ASlife и в памяти пользователя.

1. СТАРТ: прочитай `project_read claude/aslife-design-log.md` (журнал решений) и, если есть, `claude/aslife-design-system.md`. Журнал важнее этого файла: при конфликте побеждает более поздняя запись.
2. РАБОТА: применяй раздел «Дизайн-система» ниже + записи журнала.
3. ФИНИШ (после каждой содержательной задачи): допиши в журнал 1–5 строк формата
   `YYYY-MM-DD | тип (цвет/шрифт/таблица/иллюстрация/текст/процесс) | решение | источник: [stated] или [наблюдение] | задача`.
   Пиши только то, что Анна сказала сама, или то, что она приняла без правок (отметь «принято без правок»). Правки Анны к твоему варианту — самый ценный сигнал: фиксируй «было → стало».
4. Раз в ~10 записей: «усреднение» — сведи повторяющиеся решения в дизайн-систему (`aslife-design-system.md`), противоречия вынеси в «Открытые вопросы». Одиночное решение не становится правилом.
5. Не записывай: персональные/финансовые/медицинские данные, содержимое клиентских данных, выдуманные цифры.

Запись делай через `project_write` (прочитай → дополни → запиши целиком; патча нет). Если проекта нет — `memory` в /projects/…/areas/aslife-design.md.

## 2. Цвета

Бренд [stated]: красный `#EE0029`, графит `#474E57`, серый `#697586`, белый. А-Клуб: тёмно-металлический премиум с красными акцентами.

Токены памяток НСЖ (рабочая версия, светлая / тёмная):
- страница `#F2F3F6` / `#0E1014`; фон `#FFFFFF` / `#15181E`; поверхность `#FFFFFF` / `#1C2028`; мягкий `#F3F4F7` / `#20242D`
- линия `#E4E7ED` / `#2C323D`; текст `#474E57` / `#C9CFD9`; сильный текст `#1F2530` / `#F3F5F8`; серый `#5E6979` / `#9AA4B5`
- красный `#EE0029`, красный для текста `#E0002A` / `#FF5C72`; подложка `#FFF0F2` / `#2A1C20`; hero `#FFE6EA` / `#2B1A1F`
- пара продуктов: продукт 1 = графит `#474E57` (текст `#474E57` / `#A9B3C4`), продукт 2 = красный `#EE0029`.

Правила:
- Красный — акцент (цифры-герои, CTA, маркеры), не заливка всего. Графит — основной «спокойный» цвет.
- Диаграммы и графики уводить от красно-оранжевого в единую гамму шаблона (запрос Анны к деку «Юнит Линк»); данные не менять.
- Тёмная тема обязательна для HTML (prefers-color-scheme + data-theme).

## 3. Таблицы и данные

[Наблюдение из памяток, подтвердить у Анны] Данные подаются «карточками-плитками», а не плотными таблицами: цветная шапка с названием продукта (графит/красный), под ней сетка 2 колонки; главная цифра на всю ширину (34px, цвет продукта), остальные — 22px, подпись серым 13.5px. Углы 18px, тонкая рамка 1px `--line`, без тяжёлых теней.
Сравнения продуктов: два столбца/блока в цветах продуктов; слева линия 4px цвета продукта, подпись капсом 13px.
Конкурентные сравнения Unit-Link: цифры честные, но иерархия визуально выделяет продукты компании, периоды лидерства конкурентов приглушаются [stated, принятый подход].
Правила цифр: проценты и сроки в формате «21%», «3 года», «от 1 до 20 млн ₽», десятичная запятая («4,5%»), пробел перед ₽.
Графики в PPTX — только редактируемые (нативные), с заглушками данных, помеченными как примерные.

## 4. Иллюстрации и графика

- Иконки: линейные, stroke 1.8, скруглённые концы, внутри плитки 40×40, радиус 12, фон `--tint`, цвет красный.
- Hero-блок: радиальный градиент `--hero` → фон, справа 3D-/предметная иллюстрация продукта с мягкой тенью (`drop-shadow 0 6px 6px`).
- Кнопки/чипы — «пилюли» (радиус 99px), основная CTA красная, вторичная — с рамкой.
- События: кинематографичная/«супергеройская» тематика, клаппер, главы-разделители; А-Клуб — тёмный металл + красный.
- Не воспроизводить чужие логотипы, персонажей, постеры. Логотип АльфаСтрахование-Жизнь — только из файлов Анны.

## 5. Тон оф войс

[Наблюдения по памяткам и дискуссиям; уточняется журналом]
- Русский, на «вы» к клиентам; для менеджеров — коротко и по делу, без канцелярита.
- Цифра — первой, смысл — после: «21% доход на каждый взнос».
- Формула выгоды: для кого → что получает → чем защищено («для тех, кто хочет юридически защитить средства…», «без НДФЛ»).
- Слайд — минимум текста, аудитория слушает, а не читает; полный текст — в заметках докладчика.
- Заголовки — короткие, утвердительные; без восклицаний и эмодзи.
- Названия продуктов точно как в источнике (НСЖ для формирования капитала, Максимум / Максимум Плюс, Деньги в резерве, Путь к успеху, Альфа Полис, Unit Link).
- Регуляторика и налоги — нейтрально, со ссылкой на норму; ничего не обещать сверх документа.

## 6. Форматы и процесс

- Памятки НСЖ: A4 PDF (показывают клиентам) + мобильный HTML со сворачиваемыми секциями; должен работать на iPhone и Android; хостинг — российское объектное хранилище.
- Макеты: HTML-черновик → ручной перенос в Figma (плагины html.to.design, pdf.to.design). PPTX — редактируемые объекты.
- Материалы приходят в разном формате (бриф, письмо, чужие слайды): сначала нормализуй вход, укажи расхождения и что требует подтверждения.
- Для спикеров — структурированный опросник, а не просьба прислать слайды.
- Перед выдачей: сверка цифр с источником, список допущений и «что подтвердить».
