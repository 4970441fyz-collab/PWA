# Бэкап сессии: «Путь эксперта» (конкурс в Японию, выступление 02.12)

Содержимое:
- landing/site — финальный html-лендинг (index.html + assets: mp4-версии тяжёлых GIF, лепестки GIF, логотипы, шрифт Onest).
- scripts_w3/build.js + content.json — генератор лендинга (тексты в content.json; запуск: node build.js, нужна папка site/assets).
- pptx_html_v3 — генераторы первой версии: pptx.js (PPTX), html.js (HTML-слайды), scenes.js/render.js (векторные иллюстрации), anim.py (анимация PPTX).
- deliverables — выданные файлы (PPTX v3, HTML v3, фоны PNG, версии 1–2).

Решения по ходу сессии:
- Стиль: красный и чёрный, японская тематика, чередование светлых и тёмных слайдов; плашка «Что обсудить с клиентом?» красная на тёмных и чёрная на светлых.
- Пользователь сама сделала презентацию с GIF и анимацией (образец «что я ждала»); лепестки сакуры из её GIF оставлены.
- Тяжёлые GIF (до 112 МБ) пережаты в зацикленные mp4; оригиналы остались в её PPTX.
- Правки лендинга: чёрный фон без узоров, без красных полос на карточках, кот на 3-й теме без рамки, сакура в правом верхнем углу на 5-й теме, логотип при запуске.
- Текст на лендинге сверен с её текстом: 31 фрагмент, расхождений нет.
