## Чего здесь нет

- **Презентаций.** Среди артефактов их нет: деки лежат файлами (PPTX/PDF) в других чатах. Положите их в `presentations/` вручную.
- **Журнала решений и `aslife-design-system.md`** из проекта ASlife: из этой сессии проект недоступен. Экспортируйте их в `design-system/design-log.md` и `design-system/design-system.md`.
- **Свежих версий памяток.** Версия v5 (с переименованием «Комиссионный доход» и сносками) могла быть загружена в боевой репозиторий после 30.09. Сверьте с ним.
- **Шрифта Gilroy** (лицензионный), иконок и иллюстраций из Figma (в «Кабинете ИСЖ» они не синхронизированы, список в `design-system/README.md`).
- **Документов-стратегий** (стратегия памяток для руководства, инструкция по обзору рынков): внутренние, не для публичного репозитория. Экспортируются со страницы документа в Markdown или .docx.

## Публикация

GitHub Pages на бесплатном тарифе работает только с публичным репозиторием: всё, что внутри, видно всем. Рабочие и внутренние материалы держите в отдельном приватном репозитории.
